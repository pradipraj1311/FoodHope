# 🍱 FoodHope – Food Rescue App

FoodHope is a Flutter-based mobile application designed to reduce food waste and connect food donors with NGOs and volunteers.

---

## 🚀 Project Overview

FoodHope helps:

- Restaurants donate excess food  
- Volunteers collect and deliver food  
- NGOs distribute food to needy people  

---

## 👥 User Roles

### 🥘 Donor
- Add food donation  
- Set quantity & expiry  
- Track pickup  

### 🚚 Volunteer
- View available donations  
- Accept pickup requests  
- Deliver food  

### 🏢 NGO
- Receive food  
- Manage distribution  

### 🛠 Admin
- Manage users  
- Verify NGOs  
- Monitor system  

---

## 📱 Features

- Food donation listing  
- Pickup & delivery system  
- Real-time updates  
- Role-based dashboards  

---

## 🛠 Tech Stack

- Flutter 
- Firebase 
- REST API
